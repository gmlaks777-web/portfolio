# 필레몬 스튜디오 포트폴리오

## 작업 추가하는 법 (구글 시트)

1. `portfolio.csv`를 구글 시트로 가져오기 (파일 → 가져오기 → 업로드)
2. 시트에서 **파일 → 공유 → 웹에 게시** → 시트 선택, 형식 **쉼표로 구분된 값(.csv)** → 게시 → 주소 복사
3. `config.js`의 `sheetCsvUrl: ""` 따옴표 안에 그 주소 붙여넣기 (최초 1회)

이후엔 시트에 한 줄 추가만 하면 사이트에 반영됩니다 (구글 캐시 때문에 최대 5분 정도 걸릴 수 있음).

## 시트 칸 설명

| 칸 | 내용 |
|---|---|
| 공개 | `Y`면 사이트에 표시, 비우면 숨김 |
| 대표 | `Y`면 큰 카드로, 섹션 맨 앞에 표시 |
| 카테고리 | `기업` / `크리에이터` / `AI모션` / `인터랙티브` 중 하나 |
| 제목 / 클라이언트 / 연도 / 설명 | 카드에 표시되는 글 |
| 링크 | 유튜브 링크면 사이트 안에서 재생, 그 외 링크는 새 창으로 열림 |
| 썸네일 | 비우면 유튜브 썸네일 자동 사용. 다른 이미지를 쓰려면 이미지 주소 입력 |
